qTV - Qt Trace Viewer

qTV is the trace viewer of PEAT. It loads a tractor trace and shows a timeline of the MPI, OpenMP, GPU and transport events of every loaded rank and thread, with the messages between them.

Opening a trace

  • File > Load (F3) asks for a .trace.info file. The file can also be given on the command line (qTV run.trace.info) or dropped onto the window.
  • The load dialog selects the ranks and the part of the run to read. Big traces do not fit into memory as a whole: load the ranks and the time range of interest.
  • File > ReLoad (Ctrl+F3) reads another set of ranks or another time range of the same trace. The view history and the open Info / Functions / Messages windows are kept.

Files written by qTV

The file <trace>.trace.info.user next to the trace keeps the source search directories and the bookmarks of that trace. Colours, drawing options, filter flags, recent files and the window geometry are kept in the settings of the user.
