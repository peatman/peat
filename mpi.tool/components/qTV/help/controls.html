Mouse and keyboard controls

Contents | Navigation, search and analysis

Mouse

Left clickselect the event and frame the events joined with it by messages
Left button dragzoom into the dragged range
Middle button dragmove the view in time
Right buttonmenu for the event under the cursor; drag first to select a region for Functions, Messages, User regions and Statistics
Back / forward buttonsprevious / next view
Wheelscroll the ranks
Ctrl+wheelzoom at the cursor
Shift+wheelmove the view in time
Click on the bar above the time axismove the view to that place of the loaded trace
Right click in a tablecopy rows or export the table to CSV
Click on a column header of a tablesort the table by that column

Keyboard

Left / Rightmove the view in time
Home / Endstart / end of the loaded trace
Up / Down, PgUp / PgDnscroll the ranks
+ / -zoom in / out
Ctrl+Up / Ctrl+Downtaller / shorter rows
Alt+Left / Alt+Rightprevious / next view
Ctrl+Left / Ctrl+Rightprevious / next view found by Analyse
Ctrl+Rwhole loaded trace
Ctrl+Dredraw
Ctrl+Ggo to time
Ctrl+Ffind by rank and unique index
Ctrl+Shift+Ffind by function name
Ctrl+Bbookmark the view
F2save the picture
Ctrl+Shift+Ccopy the picture to the clipboard
F3 / Ctrl+F3load / reload a trace
Esccancel the loading or the rendering in progress; drop the selection
F1this help
